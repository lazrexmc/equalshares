The Roll Call

Fund proxy votes, per category, with receipts.

Funds that hold voting shares vote them on your behalf: on directors, executive pay, climate reports, mergers, at the company meetings of every stock they hold. Once a year the SEC requires each fund to file the full list of those votes (Form N-PX). It is public, and almost nobody can read it. This page is one such filing made readable: one fund, one proxy year, every vote lot, grouped by the SEC's own categories, with a receipt to the filing for every row.

How to read this page

Record, or vote lot
One row of this page. The filing reports a proposal in one or more blocks, and each block holds one or more lots: a block of shares voted one way, with its own share count. One fund can vote different lots of the same proposal differently; that is the filing's own structure, shown as filed, and it is why a proposal can appear several times. Each row says which lot of how many it is. The filing does not say what divides the lots.
Proposal
One item on one company's ballot: a director election, a pay plan, a shareholder's climate resolution. This page counts a proposal as one distinct text as filed, after ignoring letter case, spacing and trailing punctuation (the filing spells the same company and the same item more than one way). A proposal whose lots were filed under more than one category is counted in each of those categories, and its rows say where the other lots are.
% FOR
Of the lots in that cell that voted shares (a readable vote and more than 0 shares), the share voted FOR, with both counts beside it. It is split by who proposed the item because "FOR" means support for management on a management item and support for a shareholder on a shareholder item. It says nothing about what any board wanted. A "-" means no lot in that cell voted shares.
Every other term used on this page
Fund
The fund named above is one series of a larger registrant (the trust that files with the SEC). The filing, and every number on this page, covers that one series and one proxy year. The registrant is only the filer.
Proxy year
Form N-PX covers votes cast from July 1 to June 30. The period shown is the year's end date.
Category
The SEC's own category, as the fund filed it. This page does not classify anything. A record the fund tagged with several categories is counted under the first one.
Proposed by
The filing's voteSource: ISSUER means the company's own management put the item forward; SECURITY HOLDER means a shareholder did.
Voted
FOR, AGAINST, ABSTAIN, or WITHHOLD as filed. WITHHOLD is the director-election way of not supporting a nominee where AGAINST is not on the ballot. ABSTAIN is as filed; the filing does not say why a lot abstained. Anything else the filing put in this field (say-on-pay frequency answers like "ONE YEAR" or "1.0") is shown verbatim and marked unparseable; it is never guessed into one of the four.
Mgmt rec (as filed)
The filing's managementRecommendation field, reproduced verbatim on each lot. Before resting anything on it, this page tests whether it behaves like a board's recommendation (a board recommends once per item); the result for this filing is stated in "Where these numbers come from" and in the column's own header. No headline on this page is computed from it.
Unparseable / absent in source
Two different states, never merged: unparseable means the filing gave a value this page does not understand (shown raw); absent in source means the filing gave no value at all, for example a proposal filed with zero lots (a withdrawn resolution).
Shares
Share counts are as filed, fractions included (funds hold fractional shares). A lot reported with 0 shares is the fund stating that a voting block held no shares at that meeting; it is shown, counted separately, and left out of "% FOR".
Receipts
Form N-PX has no per-row anchor, so there is one receipt per filing: EDGAR's rendered vote table, stored at ingest time from the filing's own index page, never constructed. Each row gives this page's row and proposal numbers (this page's numbering, not EDGAR's) and the issuer, CUSIP and meeting date to search for in that table.
Engine run
A fingerprint of the code and configuration that computed every number here: sha256(code_fingerprint + "|" + config_hash), first 16 hex characters. It changes whenever the code or the configuration changes; two runs with the same id computed the same way. Both inputs are shown so the id can be checked with any SHA-256 tool.
Configuration
One typed number shapes what this page shows: the threshold below which a cell is marked thin, and below which the recommendation test needs more evidence. It is shown in "Where these numbers come from" and is part of the engine fingerprint.
EqualShares
An independent project that makes fund proxy votes readable. Not affiliated with any fund, registrant, or the SEC.
